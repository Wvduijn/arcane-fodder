## Verdict: PASS

- **One entry point.** CombatSystem is now the only place area damage happens. Every auto and
  projectile hit goes through core `resolveUnitHit`, every spell impact through `resolveArea`
  (`resolveAreaWithReactions`) and every ended fuse through `resolveKaboom`. Status ticks stay
  plain `applyHit`, which is correct because Burning is fire and never Combusts.
- **Per blast:** `unit:damaged` for landed hits; `status:applied` only for `'applied'` (M4
  convention); knockback routed by team (enemies to `EnemyAiSystem`, wizards to the new
  `SquadSystem.knockBack`, which wraps core `knockSquadMember`).
- **Per reaction:** `reaction:triggered`, with Combust credited to the storm hit's source and Kaboom
  to the keg (GDD §0).
- **Kegs and deaths.** Lit kegs go to KegSystem through the `KegLink` interface, and every kill is
  queued into the single per-frame flush.
- **Layering.** No rules moved into src/game. Tuning comes from data (`REACTIONS`, `COMBAT`).
- **T6 M2 is fixed, verified in game.** BurningOverlayView now re-reads `hasStatus` each frame, so
  a consumed Burning clears with no new event and no contract change. Over two no-input runs
  (≈ 640 frames each, 4 Combusts each), the set of overlays matched the set of burning units on
  every frame. Zero stale frames and zero missing frames.
