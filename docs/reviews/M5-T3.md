## Verdict: PASS

Availability is computed from the living classes on every read, and nothing stores it. Slots come
from `SpellDef.slot`, so slot 1 stays Fireball when only Stormcallers live (D3). `lostSpells` is a
pure diff of two derivations. The memoised reader returns the same array until the set of living
classes changes, so the HUD can compare by reference. Pure TypeScript with type-only imports. The
tests cover every case T3 lists, plus a 200-run seeded kill-order property test for "a lost spell
never returns".
