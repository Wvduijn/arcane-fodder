# Review M7-T16 — HUD "Huts n/2", off-screen portal arrow, intro pan, pause

Reviewer: reviewer · Date: 2026-10-22 · Owner of task: game-dev
Scope: `src/game/hud/MissionHudModel.ts`, `MissionHudWidget.ts`, `edgeArrow.ts`, the
`HudScene.ts` diff, `src/game/world/IntroPan.ts`, `src/game/scenes/PauseScene.ts` and

Serves: D4, D5.

## Verdict: PASS WITH NOTES

- **HUD model.** MissionHudModel reads the objective totals and the portal through narrow
  interfaces. It bumps `changedCount` on `mission:target-destroyed` (for the HUD pop), removes its
  listener and goes `alive: false` on destroy. HudScene renders the widget only while the model
  is alive.
- **Portal arrow.** `edgeArrow` places the arrow on a rect inset 14 px from the view edge and hides
  it when the portal is ≥ 32 px inside the view. It shows from the start, dim while sealed and
  bright once open (`portalOpen = phase !== 'sealed'`). The sealed-portal arrow request from
  level doc §9.4 is met.
- **Intro pan.** 3 s from data (`PORTAL.introPanMs`), smoothstep out, a hold, smoothstep back,
  then `beginPlay`. Any move key or a click (`spell1`/`spell2`, consumed) skips it, and restarts
  skip it (`attempt > 0`). The mission timer doesn't run during it (core `tickMission`).
- **Pause (Q6).** Esc/P pauses the whole MissionScene (clock, tweens, systems, mission timer) and
  launches PauseScene with Resume (Esc/P/click) and Restart (R/click). The `chosen` guard stops a
  double pick. The PauseScene keys are destroyed on its shutdown (Phaser `removeAllKeys(true)`,
  checked in `node_modules/phaser/src/input/keyboard/KeyboardPlugin.js:880-893`).

## Findings

### Minor

**m1. The intro pan timing differs from the level doc** — `IntroPan.ts` `SHARES = { out: 0.4,
hold: 0.2 }` gives 1.2 s out, a 0.6 s hold and 1.2 s back. Level doc §3 asks for about 1.4 s out,
about 0.2 s hold and about 1.4 s back. The longer hold arguably reads better (the dark runes are
the point), but it's a design number in game code that the level doc owns.
Fix: either level-designer updates the doc to 1.2/0.6/1.2, or the shares move into `PORTAL`
(game-designer) and the code reads them. Owner: **level-designer** or **game-designer**, as the
producer prefers.

**m2. The HUD "Huts n/2" label overlaps the debug overlay's first lines** under `?debug`
(screenshot `smoke.png`, debug view only). Debug-only, cosmetic. No action needed.
