### Nit

**n1. `int` loses uniformity for ranges wider than 2^32.** rng.ts:43 computes
`floor(next() * (max - min + 1))`, and `next()` has only 2^32 distinct values. Every MVP caller
(list indices, small rolls) is far below that. One line in the `int` doc ("ranges up to 2^32") would
stop someone using it later for timestamps or large ids.

**n2. Seed truncation is silent.** `createRng(1.9)` and `createRng(1)` give the same stream
(`>>> 0`). This is documented and tested (rng.test.ts:25-28), so it's only noted. A designer who
types a fractional `nameSeed` gets no warning, but the `as const` literal in devArena.ts makes that
unlikely.
