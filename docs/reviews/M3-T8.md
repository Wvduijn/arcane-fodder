nothing else in game holds a position. The leader steps from input and is clamped to the same feet

change. All four of my T3/T5 notes are applied. The in-game run confirms D3 and D4 end to end.

### Nit

**n1. The `kill` doc comment is over-long.** SquadSystem.ts:144 runs past the 100-column style the
rest of the file keeps. Prettier doesn't wrap comments, so it passes. Optional.

**n2. Large frame deltas.** `update(dt)` passes Phaser's delta straight through. Phaser 4's TimeStep
clamps delta to `1000 / minFps` (200 ms by default; node_modules/phaser/src/core/TimeStep.js:181,
:583-591), so after a tab switch the leader moves at most 22 px in one frame and the follower cap
scales with it. That's acceptable. I'm noting it in case `fps.minFps` is ever lowered in the game
config.
