`EnemyState` list), HP and alive/dead come from the shared `CombatWorld`, and sprites only mirror state

## Findings

### Blocker / Major / Minor
None for T9 itself. See M4-T13 M1 (the debug kill bypasses `CombatWorld`), which touches
`SquadSystem.kill`.

### Nit

**n1. `fallen` grows with every enemy death for the whole run.** (owner: game-dev)
EnemyAiSystem.ts:86, :169. Each death adds an entry that is cleared only on SHUTDOWN. It's harmless in
M4 (8 per G press), but M7 waves will spawn hundreds of goblins. Suggest deleting the entry once the death
puff has used it (for example on the frame after `unit:died`), or capping it.

**n2. The wind-up tell is subtle at 1×.** (observation for the human, not a defect)
`TELL.windupStretch` 0.2 over 150 ms is a small vertical stretch. In my stills it's hard to spot at
640×360. That's acceptable for a placeholder (the sprint allows "scale/tint pulse"), but readability
§3 makes it *the* dodge cue. The human playtest should say whether it reads; M8 art replaces it.

n1 fixed: `fallen` is cleared at the start of each `update` (EnemyAiSystem.ts:187). The death puff
