## Architecture (short plan, CLAUDE.md "present a plan before any architectural change")

One authoritative state per concern, all in core:
- **Positions:** wizards stay in core's `SquadState` (M3). Enemies get a core `EnemyState` (position,
  velocity, knockback, AI state) owned by `EnemyAiSystem`.
- **Health, statuses, alive/dead:** one core `UnitCombatState` per unit (wizards and enemies), in a
  core `CombatWorld` keyed by `EntityId`. `CombatSystem` owns it. HP bars, flash and overlays only read it.
- **Frame order** (the scene's `systems` array): input → `SquadSystem` (leader + follow) →
  `EnemyAiSystem` (brains, movement, knockback) → `TargetingSystem` → `CombatSystem` (cooldowns, fire,
  projectiles, hits, deaths) → `StatusSystem` (Burning ticks; its deaths go through `CombatSystem`) →
  views (flash, health bars, marker) → camera → debug.
- **Deaths:** core `applyHit` returns `{ dealt, killed, deathVariant, gibbed }`. `CombatSystem`
  collects the frame's deaths, sorts them by id, then calls `SquadSystem.kill(ids, …)` for wizards
  (succession unchanged) and removes enemies. It emits `unit:died` once per death.
- **Core sim:** the D2 headless test drives the same core step functions in the same order as the scene
  (`tests/core/combat/encounterSim.ts`), like M3's `tests/core/squad/sim.ts`.

Core modules (core-dev):
`core/ai/stateMachine.ts`, `core/ai/goblin.ts`, `core/combat/{cooldown,damage,death,status,projectile,knockback,world}.ts`,
`core/targeting/selectTarget.ts`, `core/enemies/enemyMovement.ts`.

## Contract changes (producer, after human approval)

### `src/core/types.ts`: add
```ts
/** Element a mage class feeds into Convergence (plan §3.1). MVP classes only. */
export type Element = 'fire' | 'storm';

/** Element of a damage source (GDD §0). Reactions key off it. */
export type DamageElement = 'fire' | 'storm' | 'arcane' | 'physical';

export type MageClassId = 'pyromancer' | 'stormcaller';
export type EnemyId = 'goblin-grunt' | 'goblin-archer';
/** Granted spells (plan §3.1). Data only in M4; SpellSystem is M5. */
export type SpellId = 'fireball' | 'lightning';
export type StatusId = 'burning';
/** How an enemy death looks, from the killing blow (GDD §12a). */
export type DeathVariantId = 'charred' | 'electrified' | 'blood';

/** Anything that deals damage (GDD §12a, §15). */
export interface DamageSourceDef {
  readonly element: DamageElement;
  readonly damage: number;
  /** 0 for none. Eased over CombatTuning.knockbackMs. */
  readonly knockbackPx: number;
  /** Can a big enough killing hit from this source gib (GDD §12a)? */
  readonly canGib: boolean;
  /** Overrides the element → variant mapping (Kaboom → blood, M5). */
  readonly deathVariant?: DeathVariantId;
  readonly applies?: StatusId;
}

/** A straight, non-homing projectile aimed at the target's position at fire time (GDD §3). */
export interface ProjectileAttackDef extends DamageSourceDef {
  readonly kind: 'projectile';
  readonly rangePx: number;
  readonly cooldownMs: number;
  /** px/s */
  readonly projectileSpeed: number;
  /** Hit circle (GDD §0: bolt, spark and arrow 4 px). */
  readonly projectileRadiusPx: number;
}

/** Melee swing: wind-up tell, then a hit if the target is still in range (GDD §12, Q3). */
export interface MeleeAttackDef extends DamageSourceDef {
  readonly kind: 'melee';
  /** Centre to centre. */
  readonly rangePx: number;
  readonly cooldownMs: number;
  /** Tell before the swing (readability §3: ≥ 100 ms). */
  readonly windupMs: number;
}

/** Archer shot: draw tell, aimed at the target's position at draw start (GDD §12). */
export interface DrawnProjectileAttackDef extends ProjectileAttackDef {
  readonly drawMs: number;
}

export interface ClassDef {
  readonly id: MageClassId;
  readonly role: 'damage';
  readonly element: Element;
  readonly maxHp: number;
  /** Per class for post-MVP; the squad moves at MovementTuning.squadMoveSpeed (GDD Q9). */
  readonly moveSpeed: number;
  readonly attack: ProjectileAttackDef;
  readonly grantsSpell: SpellId;
}

export type EnemyBehaviour =
  | { readonly kind: 'swarm' }
  /** Step back below retreatBelowPx, step in above advanceAbovePx, hold in between. */
  | { readonly kind: 'keep-range'; readonly retreatBelowPx: number; readonly advanceAbovePx: number };

export interface EnemyDef {
  readonly id: EnemyId;
  readonly maxHp: number;
  /** px/s */
  readonly moveSpeed: number;
  readonly bodyRadiusPx: number;
  readonly aggroRadiusPx: number;
  /** Re-pick the nearest wizard this often, or at once when the target dies. */
  readonly retargetMs: number;
  readonly takesKnockback: boolean;
  readonly behaviour: EnemyBehaviour;
  readonly attack: MeleeAttackDef | DrawnProjectileAttackDef;
}

/** Damage-over-time status (GDD §6). Its ticks resolve deaths by `element`. */
export interface StatusDef {
  readonly id: StatusId;
  readonly element: DamageElement;
  readonly tickDamage: number;
  readonly tickMs: number;
  readonly durationMs: number;
}

/** Shared combat tuning. */
export interface CombatTuning {
  /** Wizard auto-attack retarget interval (GDD §3). */
  readonly retargetMs: number;
  /** Auto-attack projectiles expire after rangePx × this much travel (GDD §3: 1.2). */
  readonly projectileRangeFactor: number;
  /** Knockback displacement is eased over this long (no teleport). */
  readonly knockbackMs: number;
  /** Gameplay dt is clamped to this (tab switches, hitches). */
  readonly maxFrameDtMs: number;
}

/** Gib resolution in core (GDD §12a). The visual gib keys come with art in M8. */
export interface GibTuning {
  /** Gib when the killing hit's raw damage ≥ this × target maxHp. */
  readonly overkillRatio: number;
  readonly maxGibbedPerEvent: number;
}

/** One enemy in the dev encounter, placed relative to the squad's spawn. Until M7's waves. */
export interface DevEncounterSpawn {
  readonly enemy: EnemyId;
  readonly offset: Vec2;
}
```

### `src/game/events.ts`: change
```ts
import type { DamageElement, DeathCause, DeathVariantId, EntityId, StatusId, Team } from '@core/types';

export interface GameEvents {
  /** `amount` is the HP actually lost (clamped to remaining HP, GDD §9). */
  'unit:damaged': {
    readonly id: EntityId;
    readonly team: Team;
    readonly amount: number;
    readonly source: EntityId | null;
    readonly element: DamageElement;
  };
  /** Wizards always carry `blood`/`false`; their death stays non-gory (GDD §12a). */
  'unit:died': {
    readonly id: EntityId;
    readonly team: Team;
    readonly cause: DeathCause;
    readonly deathVariant: DeathVariantId;
    readonly gibbed: boolean;
  };
  'squad:leader-changed': { readonly id: EntityId };
  'status:applied': { readonly id: EntityId; readonly status: StatusId };
  /** Ran out. Not emitted on death (`unit:died` already removes every status). */
  'status:expired': { readonly id: EntityId; readonly status: StatusId };
}
```
`status:expired` is new (not in plan §7.4): the Burning overlay needs an end signal without polling.
Debug kills keep cause `combat`, variant `blood`, `gibbed: false` (GDD §12a fallback).

## Design questions for the human
- **Q1, the D2 goblin group:** the GDD §3 verify group is 6 grunts. Archers hold 120–200 px from the nearest
  wizard and outrange both autos (220 vs 180/160) *by design* ("push or snipe", GDD §12), so a zero-input
  squad can't always reach an archer holding at 185–200 px. *Recommended:* `DEV_ENCOUNTER` = 6 grunts in a
  pack about 200 px north of the squad (inside grunt aggro) for D2, plus 2 archers placed further away
  (about 400 px east) for the archer check, which the playtester pushes manually. **G** respawns both.
- **Q2, bodies and knockback:** enemies separate from each other and yield to wizards, so wizards are never
  pushed by goblins (keeps the M3 follow, and matches GDD §13 "a crowd can't body-block the squad").
  Knockback moves the hit unit over 120 ms, eased; a grunt knocked out of range during its wind-up
  whiffs (the cooldown is still spent). *Recommended:* approve all three.
- **Q3, new tuning keys:** Grunt `windupMs` 150 (readability says ≥ 100), Archer `retargetMs` 500 (the GDD
  only gives the grunt's), `knockbackMs` 120, `maxFrameDtMs` 100. *Recommended:* approve as starting values.
- **Q4, death presentation in M4:** core resolves `deathVariant` and `gibbed` now (D6) and the event
  carries them. The view shows only a placeholder: a short coloured collapse puff per variant (charred dark
  grey, electrified cyan-white, blood maroon) and a grey puff for wizards. Corpses, decals, gibs, the
  skeleton flash, the dropped hat and the gore toggle come with art in M8. *Recommended:* placeholder now.
- **Q5, health bars now:** placeholder bars per readability §2–§3 in M4 (T12), otherwise the playtest can't
  read who is losing. *Recommended:* yes.
- **Q6, contracts:** approve the `types.ts` and `events.ts` changes above, including the new
  `status:expired` event and replacing `DevSquadConfig.size` with `classes`.
