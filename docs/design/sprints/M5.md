## Architecture (short plan, CLAUDE.md "present a plan before any architectural change")

- **One damage entry point.** Every area event (Fireball, Lightning, Combust, Kaboom) goes through a
  core `resolveAreaEvent` built on `applyEventHits` (M4 T3 n3: keeps the per-event gib cap). Game side,
  `CombatSystem` exposes it, so all deaths of a frame are still collected, sorted by id and flushed once
  (wizards to `SquadSystem.kill`, enemies removed). SpellSystem and KegSystem never touch `CombatWorld`
  directly.
- **Reactions in core.** `src/core/combat/reactions.ts` resolves Combust after any landed storm hit
  (auto spark or spell) and returns follow-ups: the Combust blast, keg triggers. `src/core/structures/keg.ts`
  owns `KegState` (idle → fuse → spent) and fuse timers. Kegs are not in `CombatWorld` (they have no HP).
- **Derived slots.** `src/core/spells/availability.ts` computes slots from living squad classes on every
  read (memoised on squad change). Nothing stores "has Fireball". `spell:lost` fires from a diff of two
  derivations, once per spell.
- **Spell casting in core.** `src/core/spells/caster.ts`: per-spell cooldowns, cast validation, aim clamp,
  pending Lightning strikes and Fireball flight (reuses `core/combat/projectile.ts`, with kegs as hit
  bodies).
- **Wizard knockback.** Kaboom pushes wizards (GDD §8). Core squad stepping gains the same eased
  knockback the enemies have; follow resumes after.
- **Frame order:** input → Squad → EnemyAi → Targeting → **Spell** (casts, telegraphs, Fireball flight) →
  **Keg** (fuses, Kaboom) → Combat (autos, projectiles, reactions, flush all frame deaths) → Status →
  views → camera → debug. HUD lives in its own scene (Q3).
- **Aim:** `GameInput.aimWorld` is already re-projected through `camera.getWorldPoint` every frame (M2).
  SpellSystem reads only that, then core clamps it to 280 px from the leader.

### `src/core/types.ts`: add
```ts
export type ReactionId = 'combust' | 'kaboom';
export type StructureId = 'powder-keg';

/** How a spell reaches its aim point (GDD §4, §15). */
export type SpellDelivery =
  /** Flies from the leader; explodes on the first enemy unit, hut or keg it touches, or at the aim point. */
  | { readonly kind: 'projectile'; readonly speed: number; readonly projectileRadiusPx: number }
  /** Telegraph at the aim point, then strikes whatever is in range at strike time. */
  | { readonly kind: 'strike'; readonly telegraphMs: number };

/** A player-cast area spell (GDD §4). Never damages wizards. */
export interface SpellDef extends DamageSourceDef {
  readonly id: SpellId;
  /** Input and HUD slot (spell1/spell2), fixed by class order in data (GDD §4). */
  readonly slot: 1 | 2;
  readonly radiusPx: number;
  readonly cooldownMs: number;
  readonly delivery: SpellDelivery;
}

export interface SpellTuning {
  /** The aim point is clamped to this distance from the leader (GDD §4). */
  readonly maxCastRangePx: number;
}

/** An instant area blast, ring drawn at radiusPx, hits by the body rule (GDD §0). */
export interface AreaBlastDef extends DamageSourceDef {
  readonly radiusPx: number;
}

/** Combust (GDD §7): a `triggerElement` hit on a unit that has `status`. */
export interface CombustDef {
  readonly id: 'combust';
  readonly status: StatusId;
  readonly triggerElement: DamageElement;
  /** GDD Q15: the origin loses the status. */
  readonly consumesStatus: boolean;
  /** Enemy units and huts only. `applies` spreads to every unit hit except the origin. */
  readonly blast: AreaBlastDef;
}

/** Kaboom (GDD §8): a powder keg hit by any `triggerElements` source. */
export interface KaboomDef {
  readonly id: 'kaboom';
  readonly triggerElements: readonly DamageElement[];
  readonly fuseMs: number;
  /** Hits everything in range, other kegs included. `applies` lands on enemy units and huts only. */
  readonly blast: AreaBlastDef;
  /** Wizards take blast damage × this (GDD Q2: 0.5). */
  readonly squadDamageMultiplier: number;
}

export type ReactionDef = CombustDef | KaboomDef;

/** Powder keg (GDD §8, readability §4). Neutral, never auto-targeted, has no HP. */
export interface KegDef {
  readonly id: StructureId;
  readonly bodyRadiusPx: number;
  /** Square collision footprint side; solid from M7's collision layer (Q1). */
  readonly footprintPx: number;
}

/** One keg in the dev arena, relative to the squad's spawn. Until M7's map. */
export interface DevKegSpawn {
  readonly offset: Vec2;
}
```

### `src/game/events.ts`: add
```ts
/** `at` is the clamped aim point; `from` is the leader at cast time (GDD Q11). */
'spell:cast': { readonly spell: SpellId; readonly from: Vec2; readonly at: Vec2 };
/** Fireball explodes or Lightning strikes. */
'spell:impact': { readonly spell: SpellId; readonly at: Vec2 };
/** The last wizard of the granting class left the squad. Once per spell per mission (GDD §5). */
'spell:lost': { readonly spell: SpellId };
/** A lost spell was pressed: no cooldown, no FX, the HUD slot shakes (GDD §4). */
'spell:denied': { readonly spell: SpellId };
/**
 * Combust: `origin` is the burning unit, `spreadTo` the units that caught Burning (ember arcs).
 * Kaboom: `origin` is the keg, `spreadTo` is empty.
 */
'reaction:triggered': {
  readonly reaction: ReactionId;
  readonly at: Vec2;
  readonly origin: EntityId;
  readonly spreadTo: readonly EntityId[];
};
/** A keg was triggered; the 72 px ring shows until Kaboom. */
'keg:fuse-started': { readonly id: EntityId; readonly at: Vec2 };
```
`unit:damaged` doc gains: "For Kaboom, `source` is the keg's id; it counts as squad-side (GDD §0 kill
credit)."

## Design questions for the human
- **Q1, keg collision in M5:** GDD §8 says kegs block movement, but there is no collision layer until M7.
  *Recommended:* kegs are not solid in M5 (wizards and goblins walk over them in the dev arena); they
  become solid tiles through M7's collision layer, where Fireball also explodes on collision tiles. Doing
  it now means throwaway circle-obstacle code in core.
- **Q2, dev arena kegs:** *Recommended:* a chain of 3 kegs 64 px apart about 400 px west of the spawn with
  a pack of 4 grunts beside it (outside every aggro at spawn, so D2's no-input fight is unchanged), and
  one keg beside each archer pair (the Ravine lesson: Lightning on the keg). All ≥ 112 px from the
  spawn. **G** respawns kegs too.
- **Q3, HUD:** *Recommended:* a separate `HudScene` running on top of MissionScene (its own camera, no
  scroll or zoom, ready for M6's meter and M8's touch buttons), reading a read-only slot view passed at
  launch plus bus events. Slots bottom-left, 24×24 placeholder icons with Q/E labels; game-designer
  writes the exact spec (T2).
- **Q4, edge rules (my calls unless you object):** pressing a spell on cooldown does nothing (no shake;
  the sweep already says why); no cast until the pointer has been over the game once; a Fireball in
  flight or a pending Lightning still lands if the leader dies or the spell is lost after the cast (same
  as autos, GDD §3); Kaboom knockback also moves the leader (eased 120 ms, input resumes after).
- **Q5, debug corner teleport:** D2 needs casts at the 4 map corners of a 2048×1536 arena. *Recommended:*
  debug key **T** (overlay visible only, ignores repeat) moves the whole squad to the next corner (inset
  so the camera clamps) and back to centre. Saves the reviewer and you a long walk each check.
- **Q6, contracts:** approve the `types.ts` and `events.ts` changes above. Also the stale plan.md §7.4
  event map (M4 gate open item 4): *recommended* I refresh it now to the real map (M4 + M5 events),
  with your approval, since `spell:*` and `reaction:triggered` change shape here.
