## Architecture (short plan, CLAUDE.md "present a plan before any architectural change")

- **New core folder `src/core/convergence/`** (plan §7.2): `meter.ts` (charge, clamp, charged-once,
  spend), `combo.ts` (`resolveCombo(livingClasses)` → `{ combo, power } | null`, pure lookup from
  `CONVERGENCES` by priority and `CONVERGENCE.scaling`), `channel.ts` (idle → channeling → striking;
  aim tracking + clamp + lock; strike timeline for `impact` and `barrage` patterns with seeded RNG
  target picks; burning-ground zones). The channel returns area events; it never touches the world.
- **All damage through the M5 entry point.** Convergence strikes, burning-ground ticks and the
  Arcane Detonation go through `CombatSystem`'s `resolveAreaEvent`, so Combust (storm bolts on
  Burning), keg triggers, gib caps and one death flush per frame all keep working.
- **Convergence source id.** Each run allocates one `EntityId` for "Convergence" (like a keg's id),
  used as `source` on its hits and on the Burning it applies. The meter ignores damage and kills
  whose source is that id (GDD §9 "no snowballing", Q3 below).
- **Squad hold.** Core squad stepping gains a `held` flag: no leader input, followers freeze in
  place (knockback still applies). Targeting/Combat skip wizard autos while held. SpellSystem and
  VolunteerSystem refuse input while a channel runs (no denied shake for spells: GDD §10 "blocked").
- **Volunteer in core `src/core/squad/volunteer.ts`**: `pickVolunteer(roster)` (last index, null when
  size < 2), `detachVolunteer(squad, id)` (leaves the roster and trail but stays a living squad-team
  unit in `CombatWorld`, so enemies can still hit it), sprint step (straight line at
  `sprintSpeed`, no separation, no autos), detonation trigger check, cooldown. Spell loss falls out of
  availability: the derived slots read the roster, so `spell:lost` fires from the existing diff.
- **Hat Hill in core `src/core/hatHill.ts`**: builds `FallenWizard` entries (cause → epitaph is view
  text, not stored). Save versioning and migrations are pure functions in `src/core/save/` (tested);
  `src/platform/storage/` holds `SaveRepository` + the `localStorage` implementation (game-dev). Never
  raw `localStorage` elsewhere.
- **Frame order:** input → Squad → EnemyAi → Targeting → **Convergence** (channel, strike timeline) →
  **Volunteer** (sprint, detonation) → Spell → Keg → Combat (flush) → Status → views → camera → debug.
  HUD stays in `HudScene` reading a read-only model.

## Contract changes (producer, after human approval)

### `src/core/types.ts`: add
```ts
export type ConvergenceId = 'meteor' | 'thunderstorm' | 'firestorm';
/** Missions with an id. The dev arena until M7 adds m01-goblin-woods. */
export type MissionId = 'dev-arena';

/** Leaves burning ground that applies a status to enemy units inside on every tick (GDD §10 Meteor). */
export interface GroundBurnDef {
  readonly radiusPx: number;
  readonly durationMs: number;
  readonly tickMs: number;
  readonly applies: StatusId;
}

/** One timed strike of a barrage, at a random enemy in the area (or a random point). */
export interface BarrageStrikeDef {
  /** From strike start. */
  readonly atMs: number;
  readonly blast: AreaBlastDef;
}

/** How a combo lands at the locked aim point (GDD §10, §15). Damage × power, never radius. */
export type ConvergencePattern =
  /** A shadow grows for fallMs, then one blast at the aim point. */
  | {
      readonly kind: 'impact';
      readonly fallMs: number;
      readonly blast: AreaBlastDef;
      readonly groundBurn: GroundBurnDef | null;
    }
  /** Timed strikes inside areaRadiusPx of the aim point over durationMs. */
  | {
      readonly kind: 'barrage';
      readonly durationMs: number;
      readonly strikes: readonly BarrageStrikeDef[];
    };

/** A Convergence combo (plan §4.1). The highest priority whose `requires` all live wins. */
export interface ConvergenceDef {
  readonly id: ConvergenceId;
  readonly requires: readonly Element[];
  readonly priority: number;
  /** Preview ring and barrage area (GDD §10). */
  readonly radiusPx: number;
  readonly pattern: ConvergencePattern;
}

/** Meter and channel tuning (GDD §9, §10). */
export interface ConvergenceTuning {
  readonly meterMax: number;
  readonly meterStart: number;
  /** Per HP actually dealt to enemy units and huts (overkill excluded). */
  readonly chargePerDamage: number;
  readonly chargePerKill: number;
  /** Wired in M7. */
  readonly chargePerHutDestroyed: number;
  /** Wired in M7 (GDD Q20). */
  readonly chargeOnPortalOpen: number;
  readonly channelMs: number;
  /** Index = living mages − 1 (plan §4.1: 1.0 / 1.5 / 2.0 / 2.5). */
  readonly scaling: readonly number[];
}

/** Volunteer! (GDD §11). The blast hits enemy units, huts and kegs, never wizards (Q7). */
export interface VolunteerTuning {
  /** px/s */
  readonly sprintSpeed: number;
  readonly fuseMs: number;
  readonly cooldownMs: number;
  readonly blast: AreaBlastDef;
}

/** One lost wizard on Hat Hill (plan §7.4). The epitaph is derived from `cause`. */
export interface FallenWizard {
  readonly name: string;
  readonly classId: MageClassId;
  readonly missionId: MissionId;
  readonly cause: DeathCause;
}
```

### `src/game/events.ts`: add (replaces the "planned" M6 rows in plan §7.4)
```ts
/** The meter reached max. Once per fill. */
'convergence:charged': Record<string, never>;
/** R/Space with a full meter: the meter is spent and the channel starts. */
'convergence:channel-started': { readonly leader: EntityId };
/** R/Space without a full meter, or while one runs: the HUD meter shakes. */
'convergence:denied': Record<string, never>;
/** Channel ended: the combo and power resolved from the squad alive now (GDD Q5); `at` is locked. */
'convergence:released': { readonly combo: ConvergenceId; readonly power: number; readonly at: Vec2 };
/** One blast of the strike (Meteor's impact, each meteorlet or bolt). For FX. */
'convergence:impact': { readonly combo: ConvergenceId; readonly at: Vec2; readonly radiusPx: number };
/** The squad was wiped mid-channel: nothing resolves (GDD §10). */
'convergence:cancelled': Record<string, never>;
/** F accepted: `id` left the squad and sprints; `bark` is the line shown. */
'volunteer:started': { readonly id: EntityId; readonly name: string; readonly bark: string; readonly at: Vec2 };
/** F refused (cooldown, 1 wizard, channel running): the HUD indicator shakes. */
'volunteer:denied': Record<string, never>;
/** Arcane Detonation. `unit:died` with cause `volunteer` follows in the same flush. */
'volunteer:detonated': { readonly id: EntityId; readonly name: string; readonly at: Vec2 };
```

## Design questions for the human
- **Q1, channel interrupt (plan §10 asks):** ADR 0005 already approved **A, damage never interrupts**;
  deaths mid-channel lower power and can change the combo at strike. *Recommended:* keep A. Confirm.
- **Q2, Hat Hill persistence now:** there is no `src/platform` yet. *Recommended:* build the versioned
  save now (core migrations + `platform/storage` LocalStorage repo), and append the volunteer's entry
  when they detonate. M7 adds `combat` and `left-behind` entries at mission end. Alternative: record
  in memory only and persist in M7 (less to build, but plan §10 says "record in the save model").
- **Q3, what counts as Convergence charge:** *Recommended:* Convergence strikes and the Burning (incl.
  burning ground) they apply never charge. Reactions they cause (Combust from Firestorm bolts, Kaboom
  from a strike) do charge, since the player set them up. Volunteer and Kaboom damage charge (GDD §11,
  §0 kill credit).
- **Q4, HUD:** *Recommended:* the meter is a horizontal bar bottom-centre (the slots stay
  bottom-left), with an "R" label and a glow when full; a small Volunteer icon with "F" right of the
  spell slots showing cooldown like a spell slot and a grey look when only the leader is left.
- **Q5, barks:** *Recommended:* game-designer writes 12 lines, ≤ 28 characters, dark-comedy rookie
  voice (ADR 0005 R8), seeded pick without repeating the last line; shown as a small bubble over the
  volunteer for the sprint. You review the list in T1's review.
- **Q6, M5 carry-overs:** after your M5 playtest, do you want (a) the Combust spread-delay rule, or
  (b) "Combust never lights kegs", in M6? *Recommended:* neither unless your playtest said the pop
  felt weak or the keg felt unfair.
- **Q7, contracts:** approve the `types.ts` and `events.ts` changes above, and the plan.md §7.4 refresh.

My calls unless you object: pressing R without a full meter gives a denied shake; spells pressed during
the channel do nothing (no shake); a Kaboom can still push wizards mid-channel; the volunteer can be
targeted and killed by enemies while sprinting (they blow up where they fall); Convergence itself
never damages wizards, but a keg it lights still Kabooms at the normal ×0.5 on wizards in range.
