## Tooling rules (human decision, 2026-10-12)
- **pnpm only.** Install with `pnpm add -E` (exact pins). Scripts run as `pnpm <script>`. Never npm/npx/yarn.
  `pnpm install` is allowed in .claude/settings.json; npm/npx/yarn are denied. Add `packageManager` to package.json.
- **context7 MCP** for every library API (Phaser 4, Vite, Vitest, ESLint, typescript-eslint, Prettier) before writing code.
- Logical resolution **640×360** (Q2 answered).

## Pinned versions (exact, no `^`)
Phaser `4.2.1` (latest stable). Vite, TypeScript, Vitest, ESLint, typescript-eslint, Prettier:
latest stable at install time, pinned exact in package.json. Node `>=22` in `engines`, `.nvmrc` = `22`.
